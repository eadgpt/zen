# Zen

An interactive 3D scene for the browser: a koi pond, a dry sand garden you can rake, and a mountain lake where you can skip stones.

**Open it:** https://eadgpt.github.io/zen/

- Move the pointer over water to stir it; over sand to rake it. Drag to look around.
- Lake: press and hold to charge a throw, release to skip a stone.
- Works best in a desktop browser with a decent graphics card.

Built with [three.js](https://threejs.org/) (MIT). No build step — plain files.
Sound recordings and their licences are listed in [sounds/CREDITS.md](sounds/CREDITS.md).

To run locally: `python3 serve.py`, then open http://localhost:8791
